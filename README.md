## About

A *Dark Stories*-style card game: each card tells a short real-world mystery linked to one Sustainable Development Goal, and flipping it reveals the solution. It covers the 17 UN goals plus an extra 18th-goal page, with 10 riddles per goal. Built with plain HTML, CSS and JavaScript.

## Features

- One page per goal, 10 riddles each
- 3D card-flip animation
- Light/dark theme saved in the browser
- Responsive layout

## Tech stack

| Layer | Technology |
|---|---|
| Front-end | HTML5, CSS3 (Grid, Flexbox, custom properties, 3D transforms), JavaScript ES6 |

## Getting started

No build step. Open `jogo completo/index.html` in a browser, or serve the folder:

```bash
npx serve "jogo completo"
```
