## Sobre

Jogo de cartas no estilo *Dark Stories*: cada carta conta um mistério curto ligado a um ODS e, ao virar, revela a solução. Cobre os 17 objetivos da ONU e uma página extra de um 18º objetivo, com 10 enigmas por objetivo. Feito com HTML, CSS e JavaScript puros.

## Funcionalidades

- Uma página por objetivo, 10 enigmas cada
- Animação 3D de virar a carta
- Tema claro/escuro salvo no navegador
- Layout responsivo

## Stack

| Camada | Tecnologia |
|---|---|
| Front-end | HTML5, CSS3 (Grid, Flexbox, custom properties, 3D transforms), JavaScript ES6 |

## Como rodar

Sem etapa de build. Abra `jogo completo/index.html` no navegador ou sirva a pasta:

```bash
npx serve "jogo completo"
```
